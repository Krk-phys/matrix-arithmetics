#### Ключевые алгоритмы

**Определитель**

Поиск определителя матрицы осуществляется через LU-разложение исходной матрицы, дальнейший подсчет определителя осуществялется по верхнетреугольной компоненте. Реализованное разложение является разложением не исходной матрицы, а преобразованной линейными операциямми над строками, не меняющими определитель.

Теоретическая сложность алгоритма через линейные операции с строками - $O(n^3)$ 

**Обратная матрица**

Поиск обратной матрицы осуществляется по алгоритму Гаусса-Жордана. По своей сути он почти идентичен приведению матрицы к верхнетреугольному виду, однако требует больше операций на зануление значений над главной диагональю.

Теоретическая сложность алгоритма - $O(n^3)$ 


**Главное узкое место (bottleneck) моего решения:**  

Файл matrix.py строки с 159 по 168 и с 196 по 201.
Часть алгоритма по перестановке утсранению нуля на главной диагонали во время поиска определителя и обратной матрицы занимают лишний $O(n^3)$ в алгоритме
